# Student Grade Management System 🎓

A simple **Python-based Student Grade Management System** developed as a **Python Essentials project**. The application allows users to add student details, enter marks, calculate total and percentage, assign grades, determine pass/fail status, and display student records.

📌 Project Overview

Managing student marks manually can involve repetitive calculations and may lead to calculation errors. This project provides a simple console-based solution that automates basic student result processing.

The project is designed using fundamental Python concepts and does not require any external libraries.

🎯 Objectives

The main objectives of this project are:

* To store student information.
* To accept marks for five subjects.
* To calculate total marks.
* To calculate percentage.
* To assign a grade based on percentage.
* To determine whether a student has passed or failed.
* To display student records.
* To demonstrate fundamental Python programming concepts.


## Features

* 👨‍🎓 Add student details
* 📝 Enter marks for 5 subjects
* 🧮 Calculate total marks
* 📊 Calculate percentage
* 🏆 Automatically assign grades
* ✅ Determine PASS/FAIL status
* 📋 Display all student records
* 🔄 Menu-driven interface
* 🚪 Exit option
* ❌ Handles invalid menu choices

## 📈 Grading System

The application uses the following grading criteria:

| Percentage | Grade |
| ---------: | :---: |
|     90–100 |   A+  |
|      80–89 |   A   |
|      70–79 |   B   |
|      60–69 |   C   |
|      50–59 |   D   |
|   Below 50 |   F   |

### Result Criteria

* **40% or above → PASS**
* **Below 40% → FAIL**
